This is a one-byte-plus heap out-of-bounds read in opensc's driver for a security-token vendor's proprietary object format, occurring during ordinary token-initialization while the driver decodes one of an object's fixed numeric attributes into a plain integer value. Each on-card object is cached the first time it is touched: a byte buffer is allocated to exactly the size the object's length field claimed at that moment, filled with bytes read from the card, and attached to a per-identifier table entry returned by an identifier-based lookup. Nothing prevents the same object identifier from being registered more than once, each time with its own independently declared length; because caching short-circuits once any data is already attached to an entry, a lookup that resolves to a buffer cached at an earlier, smaller declared length can still be paired with a table entry whose length field reflects a later, larger registration of the very same identifier -- the two are never reconciled. When the driver later walks that object's attribute records looking for a specific numeric attribute, it finds a matching record and hands the caller a value pointer and length taken from that record -- both ultimately bounded by the entry's current (larger, but wrong) length rather than the true, smaller allocation. The generic big-endian integer decoder underneath then unconditionally reads four fixed byte positions starting at that pointer, and several of those reads land past the end of the true, smaller allocation. Because every quantity involved -- the object's cached size, its currently-recorded declared length, and the attribute record's own offset/length fields -- comes directly from bytes the card supplied across its normal object-listing and per-object detail responses, a token (or anything able to substitute a token's responses) that reports the same object identifier more than once with different declared sizes reaches this exact overread through the driver's regular initialization sequence, without needing any protocol-illegal or otherwise unrepresentable response.
