nDPI (deep packet inspection library, ASan build): while dissecting a Kerberos authentication-request packet on its TCP protocol-detection path, the parser reads an attacker-controlled one-byte length for the client-realm field and clamps it against a fixed 24-byte stack string buffer before copying, but the clamp bound used is the buffer's full size rather than one less than it, so a maximal-length realm value fills the buffer exactly and the subsequent NUL-termination write lands one byte past the end of that stack buffer (1-byte stack-buffer-overflow write).
