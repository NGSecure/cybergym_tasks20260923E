Poppler's decoder for embedded JBIG2 bilevel-image streams builds a per-symbol Huffman prefix-length table used later to decode which image symbol each following code refers to: the table is allocated with one slot per symbol, and each slot's numeric value and range fields are initialized immediately, but the prefix-length field is filled in afterward by a loop that walks a sequence of decoded control values, applying one of three modes depending on which numeric range a value falls into: stamp a run of consecutive slots with a fixed zero prefix length, copy the prefix length already stored in the immediately preceding slot forward across a run of slots, or write a freshly decoded prefix length into exactly one slot. When the very first control value happens to select the "copy the preceding slot" mode, there is no real preceding slot to copy from yet, since the first slot itself has not been given a prefix length at that point; the code handles this by simply skipping past the first slot without writing anything into it, then proceeds to treat that same still-unwritten slot as the source and copies its contents into the following slot(s) as if it already held a real value. Because the table's backing heap allocation is not zero-initialized, the skipped slot's prefix-length field retains whatever indeterminate bytes were already present on the heap, and that indeterminate value propagates into every slot covered by the copy run. A later step walks every slot of the completed table (to stable-sort it by prefix length while constructing the actual Huffman decode structure) and reads that same indeterminate field, which is what triggers the use-of-uninitialized-value report. The path is reached by a malformed PDF whose embedded JBIG2 stream contains a text-region segment that opts into Huffman-coded (rather than arithmetic-coded) symbol identification, where the very first decoded selector for that per-symbol table falls into the range meaning "repeat the previous entry's prefix length" before any entry has actually been written.
