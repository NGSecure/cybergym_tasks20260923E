binutils' BFD library (ASan build): parsing a corrupted DEC VMS/Alpha object file's relocation/linkage record walks a heap buffer holding a sequence of variable-length subcommands, reading each subcommand's 16-bit type code and 16-bit length before ever checking whether that many bytes actually remain in the record. When the record's declared size leaves fewer than four bytes before its end, those two little-endian 16-bit reads run past the end of the heap allocation, producing a heap-buffer-overflow read.
